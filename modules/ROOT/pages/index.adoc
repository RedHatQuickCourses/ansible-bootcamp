== Introduction

Welcome to Ansible Boot Camp Day 1. This intensive, hands-on course is designed to transition you from basic automation concepts to managing enterprise-grade infrastructure using Ansible Automation Platform (AAP) 2.6. As organizations scale, the need for standardized, repeatable, and scalable automation becomes critical. This course focuses on the architectural foundations and modern delivery workflows required to succeed with AAP in a cloud-native world.

This course provides a deep dive into the architecture and operational management of Ansible Automation Platform 2.5+. We begin by exploring tested topologies to ensure your infrastructure is built for high availability and performance. Moving into execution, participants will deploy AAP on Azure, gaining firsthand experience with managed cloud offerings.

The core of the day focuses on the "Automation Controller" through a Configuration-as-Code (CaC) lens—teaching you how to manage the platform itself using Ansible. Finally, we bridge the gap between operations and development by implementing the Content Developer Lifecycle, where you will learn to build, test, and promote automation content using modern DevOps principles and Execution Environments.

Duration: 4 hours

== Objectives

On completing this course, you should be able to:

- Evaluate and Select AAP Topologies: Identify the ideal architectural design (Base, Scaled, or Mesh) for specific enterprise requirements, ensuring low latency and high availability across hybrid-cloud environments.

- Provision AAP in Cloud Environments: Successfully deploy and initialize the Ansible Automation Platform on Microsoft Azure, understanding the nuances of managed identity, networking, and cloud-native integration.

- Implement Configuration-as-Code (CaC): Apply the "Platform managing the Platform" philosophy by using Ansible playbooks to programmatically configure users, inventories, credentials, and job templates within the Automation Controller.

- Master the Developer Lifecycle: Execute a full content workflow—from local development to production—incorporating Execution Environments (EE), version control integration, and the principles of reusable, modular automation content.

== Prerequisites

This course assumes that you have the following prior experience:

- Basic understanding of Git, Linux, Azure, OpenShift and Ansible Automation platform.
